# 🏰 AI Gesture Castle

An interactive gothic castle experience controlled entirely through real-time webcam hand gestures.

This weekend project combines **HTML, CSS, JavaScript, and hand gesture recognition** to bring a dark fantasy castle to life. Inspired by gothic architecture and dark academia aesthetics, the experience lets you control the castle's lighting, candles, music, volume, and atmosphere using your hands.

## ✨ Features

- 🕯️ **Interactive Lighting** — Turn individual castle lights on or off, including the chandelier, windows, columns, and floor glow.
- 🎵 **Music Control** — Play, pause, switch between tracks, and adjust the volume using hand gestures.
- 🔥 **Candle Effects** — Control the castle's candle flames.
- 🌙 **Atmosphere Modes** — Switch between different moods, including Enchanted, Moonlit, and Vampire modes.
- ✋ **Real-Time Hand Gestures** — Interact with the castle through your webcam.
- 🏰 **Gothic Visual Design** — A dark, elegant castle atmosphere featuring stained-glass windows, chandeliers, and architectural details.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Webcam-based hand gesture recognition

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/Habiba-404-11-11/weekend-projects.git
   ```

2. Open the project folder.

3. Open `gesture-castle.html` in your browser.

4. Allow camera access when prompted.

5. Raise your hands and explore the castle using gestures!

**Note:** Camera access and gesture recognition may require running the project through a local development server, depending on your browser and implementation.
